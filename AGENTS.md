## Brand implementation
- Keep the platform name centralized in the brand configuration so all page titles and interface labels stay consistent.
- Use the shared global semantic color tokens for the site-wide appearance so all video and account views follow the same theme.
- Import the bundled logo image in the shared navigation and use its symbol for the favicon so the identity stays consistent.
